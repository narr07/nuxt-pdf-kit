Composable ini berfungsi untuk mengontrol mode tampilan (*view mode*) dan mode gulir (*scroll mode*) pada viewer PDF.

## Cara Penggunaan

```ts
const {
  viewMode,
  scrollMode,
  setViewMode,
  setScrollMode,
} = usePdfKitViewMode()
```

## Opsi

```ts
usePdfKitViewMode({
  initialViewMode: 'single',
  initialScrollMode: 'vertical',
})
```

| Opsi | Tipe | Default | Deskripsi |
|--------|------|---------|-------------|
| `initialViewMode` | `ViewMode` | `'single'` | Mode tampilan awal |
| `initialScrollMode` | `ScrollMode` | `'vertical'` | Mode gulir awal |

## Nilai Kembalian

| Properti | Tipe | Deskripsi |
|----------|------|-------------|
| `viewMode` | `Ref<ViewMode>` | Mode tampilan saat ini |
| `scrollMode` | `Ref<ScrollMode>` | Mode gulir saat ini |
| `setViewMode` | `(mode: ViewMode) => void` | Mengatur mode tampilan |
| `setScrollMode` | `(mode: ScrollMode) => void` | Mengatur mode gulir |

## Tipe Data

```ts
type ViewMode = 'single' | 'dual' | 'dual-cover'
type ScrollMode = 'vertical' | 'horizontal' | 'wrapped' | 'page'
```

## Mode Tampilan

| Mode | Deskripsi |
|------|-------------|
| `single` | Menampilkan satu halaman dalam satu waktu |
| `dual` | Menampilkan dua halaman berdampingan |
| `dual-cover` | Menampilkan dua halaman dengan halaman pertama sebagai sampul |

## Mode Gulir

| Mode | Deskripsi |
|------|-------------|
| `vertical` | Menggulir halaman secara vertikal |
| `horizontal` | Menggulir halaman secara horizontal |
| `wrapped` | Menampilkan halaman dalam tata letak grid |
| `page` | Navigasi halaman per halaman |

## Contoh

```vue
<template>
  <div class="flex gap-4">
    <div>
      <p>Mode Tampilan:</p>
      <UButtonGroup>
        <UButton
          :variant="viewMode === 'single' ? 'solid' : 'outline'"
          @click="setViewMode('single')"
        >
          Single
        </UButton>
        <UButton
          :variant="viewMode === 'dual' ? 'solid' : 'outline'"
          @click="setViewMode('dual')"
        >
          Dual
        </UButton>
      </UButtonGroup>
    </div>

    <div>
      <p>Mode Gulir:</p>
      <UButtonGroup>
        <UButton
          :variant="scrollMode === 'vertical' ? 'solid' : 'outline'"
          @click="setScrollMode('vertical')"
        >
          Vertical
        </UButton>
        <UButton
          :variant="scrollMode === 'horizontal' ? 'solid' : 'outline'"
          @click="setScrollMode('horizontal')"
        >
          Horizontal
        </UButton>
      </UButtonGroup>
    </div>
  </div>
</template>

<script setup>
const {
  viewMode,
  scrollMode,
  setViewMode,
  setScrollMode
} = usePdfKitViewMode()
</script>
```

```vue [ExampleViewMode.vue]
<script setup lang="ts">
const totalPages = 8
const currentPage = ref(1)

const { viewMode, pagesPerView, setViewMode, getVisiblePages } = usePdfKitViewMode()

const modes = ['single', 'dual', 'dual-cover'] as const
const visiblePages = computed(() => getVisiblePages(currentPage.value, totalPages))
</script>

<template>
  <div class="flex w-full flex-col items-center gap-4">
    <div class="flex flex-wrap items-center justify-center gap-2">
      <UButton
        v-for="mode in modes"
        :key="mode"
        :label="mode"
        :color="mode === viewMode ? 'primary' : 'neutral'"
        :variant="mode === viewMode ? 'solid' : 'outline'"
        @click="setViewMode(mode)"
      />
    </div>

    <div class="flex items-center gap-2">
      <UButton
        icon="i-lucide-chevron-left"
        color="neutral"
        variant="outline"
        aria-label="Previous page"
        :disabled="currentPage <= 1"
        @click="currentPage--"
      />
      <span class="w-40 text-center tabular-nums">Current page {{ currentPage }} of {{ totalPages }}</span>
      <UButton
        icon="i-lucide-chevron-right"
        color="neutral"
        variant="outline"
        aria-label="Next page"
        :disabled="currentPage >= totalPages"
        @click="currentPage++"
      />
    </div>

    <div class="flex h-32 w-full items-center justify-center gap-2 rounded-md border border-default">
      <div
        v-for="page in visiblePages"
        :key="page"
        class="flex h-24 w-16 items-center justify-center rounded-sm border border-default bg-elevated text-sm"
      >
        {{ page }}
      </div>
    </div>

    <p class="text-sm text-muted">
      {{ pagesPerView }} page(s) per view, showing {{ visiblePages.join(' and ') }}
    </p>
  </div>
</template>
```
