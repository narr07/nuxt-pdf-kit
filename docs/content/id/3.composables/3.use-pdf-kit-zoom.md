Composable ini berfungsi untuk mengatur kontrol zoom dan skala pada viewer PDF.

## Cara Penggunaan

```ts
const {
  scale,
  zoomMode,
  zoomIn,
  zoomOut,
  setZoom,
  zoomPercentage,
  zoomPresets,
} = usePdfKitZoom()
```

## Opsi

```ts
usePdfKitZoom({
  initialScale: 1.0,
  minScale: 0.25,
  maxScale: 10.0,
  scaleDelta: 1.1,
})
```

| Opsi | Tipe | Default | Deskripsi |
|--------|------|---------|-------------|
| `initialScale` | `number \| ZoomLevel` | `1.0` | Skala atau mode zoom awal |
| `minScale` | `number` | `0.25` | Skala zoom minimum yang diizinkan |
| `maxScale` | `number` | `10.0` | Skala zoom maksimum yang diizinkan |
| `scaleDelta` | `number` | `1.1` | Pengali untuk zoom in/out |

## Nilai Kembalian

| Properti | Tipe | Deskripsi |
|----------|------|-------------|
| `scale` | `Ref<number>` | Skala zoom saat ini |
| `zoomMode` | `Ref<ZoomLevel>` | Mode zoom saat ini |
| `zoomIn` | `() => void` | Menambah level zoom |
| `zoomOut` | `() => void` | Mengurangi level zoom |
| `setZoom` | `(value: number \| ZoomLevel) => void` | Mengatur zoom spesifik |
| `zoomPercentage` | `ComputedRef<number>` | Zoom dalam persentase |
| `zoomPresets` | `number[]` | Preset zoom yang tersedia |

## Tipe ZoomLevel

```ts
type ZoomLevel = 'auto' | 'page-fit' | 'page-width' | number
```

## Contoh

```vue
<template>
  <div class="flex items-center gap-2">
    <UButton @click="zoomOut">-</UButton>
    <span>{{ zoomPercentage }}%</span>
    <UButton @click="zoomIn">+</UButton>
    <UButton @click="setZoom('page-fit')">Pas Halaman</UButton>
    <UButton @click="setZoom('page-width')">Pas Lebar</UButton>
  </div>
</template>

<script setup>
const { 
  zoomIn,
  zoomOut,
  setZoom,
  zoomPercentage
} = usePdfKitZoom()
</script>
```

```vue [ExampleZoom.vue]
<script setup lang="ts">
const { scale, zoomPercentage, zoomIn, zoomOut, setZoom } = usePdfKitZoom({
  minScale: 0.5,
  maxScale: 3,
})

<template>
  <div class="flex w-full flex-col items-center gap-4">
    <div class="flex items-center gap-2">
      <UButton
        icon="i-lucide-zoom-out"
        color="neutral"
        variant="outline"
        aria-label="Zoom out"
        @click="zoomOut"
      />
      <span class="w-14 text-center tabular-nums">{{ zoomPercentage }}%</span>
      <UButton
        icon="i-lucide-zoom-in"
        color="neutral"
        variant="outline"
        aria-label="Zoom in"
        @click="zoomIn"
      />
      <UButton
        label="Reset"
        color="neutral"
        variant="ghost"
        @click="setZoom(1)"
      />
    </div>

    <div class="flex h-48 w-full items-center justify-center overflow-hidden rounded-md border border-default">
      <div
        class="flex h-16 w-12 items-center justify-center rounded-sm border border-default bg-elevated text-xs transition-transform"
        :style="{ transform: `scale(${scale})` }"
      >
        Page
      </div>
    </div>
  </div>
</template>
```
