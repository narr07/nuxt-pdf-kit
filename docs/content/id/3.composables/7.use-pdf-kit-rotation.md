Mengelola rotasi dokumen.

## Penggunaan

```ts
const {
  rotation,
  rotateClockwise,
  rotateCounterclockwise,
  setRotation,
} = usePdfKitRotation()
```

## Opsi

```ts
usePdfKitRotation({
  initialRotation: 0,
})
```

| Opsi | Tipe | Default | Deskripsi |
|--------|------|---------|-------------|
| `initialRotation` | `number` | `0` | Rotasi awal dalam derajat |

## Nilai yang Dikembalikan

| Properti | Tipe | Deskripsi |
|----------|------|-------------|
| `rotation` | `Ref<number>` | Rotasi saat ini (0, 90, 180, 270) |
| `rotateClockwise` | `() => void` | Putar +90° |
| `rotateCounterclockwise` | `() => void` | Putar -90° |
| `setRotation` | `(degrees: number) => void` | Atur rotasi ke sudut tertentu |

## Contoh

```vue
<template>
  <div class="flex items-center gap-2">
    <UButton @click="rotateCounterclockwise">
      <UIcon name="i-lucide-rotate-ccw" />
    </UButton>
    <span>{{ rotation }}°</span>
    <UButton @click="rotateClockwise">
      <UIcon name="i-lucide-rotate-cw" />
    </UButton>
    <UButton @click="setRotation(0)">Reset</UButton>
  </div>
</template>

<script setup>
const { 
  rotation, 
  rotateClockwise, 
  rotateCounterclockwise,
  setRotation
} = usePdfKitRotation()
</script>
