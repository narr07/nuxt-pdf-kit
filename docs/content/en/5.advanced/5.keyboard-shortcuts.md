Nuxt PDF Kit includes built-in keyboard shortcuts.

## Navigation

| Key | Action |
|-----|--------|
| `←` or `↑` | Previous page |
| `→` or `↓` | Next page |

## Zoom

| Key | Action |
|-----|--------|
| `+` or `=` | Zoom in |
| `-` | Zoom out |

## Search

| Key | Action |
|-----|--------|
| `Ctrl` / `Cmd` + `F` | Focus the search input |

## Other

| Key | Action |
|-----|--------|
| `Escape` | Exit fullscreen, clear search, and close menus |

## Usage Tips

::tip
Shortcuts only fire when the viewer has focus and you are not typing inside an input field. Click on the viewer before using keyboard shortcuts.
::

::alert{type="info"}
Keyboard shortcuts are registered while the viewer is mounted. Note that a single `Escape` press will trigger all available Escape actions at once (exit fullscreen, clear search, close menu).
::
